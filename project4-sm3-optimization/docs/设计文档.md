# SM3哈希算法优化实现技术文档

## 项目概述

本项目实现了中国国家密码管理局发布的SM3密码杂凑算法（GB/T 32905-2016），并提供了多种优化版本以提升计算性能。SM3是一种安全的密码杂凑函数，输出长度为256位，广泛应用于数字签名、消息认证码、随机数生成等密码学应用中。

## 算法规范

### SM3算法特性
- **输出长度**: 256位（32字节）
- **分组长度**: 512位（64字节）
- **字长度**: 32位
- **迭代次数**: 64轮
- **安全强度**: 128位
- **标准依据**: GB/T 32905-2016, GM/T 0004-2012

### 核心组件
1. **初始值**: 8个32位常数
2. **常数T**: 两个不同的32位常数用于不同轮次
3. **布尔函数**: FF和GG函数，前16轮和后48轮使用不同定义
4. **置换函数**: P0和P1用于非线性变换
5. **消息扩展**: 将16个字扩展为68个字和64个字

## 3. SM3算法数学理论

### 3.1 SM3哈希函数数学定义

#### 3.1.1 基本数学结构

SM3哈希函数H: {0,1}* → {0,1}^256定义为：
```
H(M) = SM3(IV, pad(M))
```

其中：
- M: 任意长度输入消息
- IV: 8个32位初始值
- pad(M): 填充后的消息

**初始值定义**：
```
IV₀ = 7380166F  IV₁ = 4914B2B9  IV₂ = 172442D7  IV₃ = DA8A0600
IV₄ = A96F30BC  IV₅ = 163138AA  IV₆ = E38DEE4D  IV₇ = B0FB0E4E
```

#### 3.1.2 消息填充算法

对于长度为l比特的消息M，填充算法为：
```
M' = M || 1 || 0^k || l
```

其中：
- k = 448 - (l + 1) mod 512
- l用64位二进制表示
- |M'| = 512n (n为正整数)

**填充正确性证明**：
```
|M'| = l + 1 + k + 64 = l + 1 + (448 - (l + 1) mod 512) + 64
     = l + 1 + 448 - (l + 1) mod 512 + 64
     = (l + 1) + 512 - (l + 1) mod 512 
     ≡ 0 (mod 512)
```

#### 3.1.3 消息扩展数学模型

**基本扩展函数**：
```
W_j = {
  M_j,                           if 0 ≤ j ≤ 15
  P₁(W_{j-16} ⊕ W_{j-9} ⊕ (W_{j-3} ≪ 15)) ⊕ (W_{j-13} ≪ 7) ⊕ W_{j-6},  if 16 ≤ j ≤ 67
}
```

**置换函数P₁定义**：
```
P₁(X) = X ⊕ (X ≪ 15) ⊕ (X ≪ 23)
```

**扩展字W'_j**：
```
W'_j = W_j ⊕ W_{j+4},  for j = 0,1,...,63
```

**代数展开**：
设F(x,y,z) = x ⊕ y ⊕ (z ≪ 15)，则：
```
W_{j+16} = P₁(F(W_j, W_{j+7}, W_{j+13})) ⊕ (W_{j+3} ≪ 7) ⊕ W_{j+10}
```

这构成了一个16阶线性递推关系。

### 3.2 压缩函数数学分析

#### 3.2.1 布尔函数定义

**FF函数族**：
```
FF_j(X,Y,Z) = {
  X ⊕ Y ⊕ Z,           if 0 ≤ j ≤ 15
  (X ∧ Y) ∨ (X ∧ Z) ∨ (Y ∧ Z),  if 16 ≤ j ≤ 63
}
```

**GG函数族**：
```
GG_j(X,Y,Z) = {
  X ⊕ Y ⊕ Z,           if 0 ≤ j ≤ 15
  (X ∧ Y) ∨ (¬X ∧ Z),  if 16 ≤ j ≤ 63
}
```

**布尔函数性质分析**：
- FF₀和GG₀在前16轮都是XOR函数，具有最佳的雪崩效应
- FF₁是多数函数，满足FF₁(X,Y,Z) = maj(X,Y,Z)
- GG₁是条件函数，满足GG₁(X,Y,Z) = (X∧Y) ∨ (¬X∧Z) = if X then Y else Z

#### 3.2.2 置换函数数学表示

**P₀置换函数**：
```
P₀(X) = X ⊕ (X ≪ 9) ⊕ (X ≪ 17)
```

**线性变换特性**：
P₀是F₂³²上的线性变换，其矩阵表示为32×32的二进制矩阵。

**分支数计算**：
P₀的分支数为3，即对于任意非零输入x：
```
wt(x) + wt(P₀(x)) ≥ 3
```

其中wt(x)是x的汉明重量。

#### 3.2.3 压缩函数轮函数

**单轮变换**：
```
SS₁ = ((A ≪ 12) + E + (T_j ≪ j)) ≪ 7
SS₂ = SS₁ ⊕ (A ≪ 12)
TT₁ = FF_j(A,B,C) + D + SS₂ + W'_j
TT₂ = GG_j(E,F,G) + H + SS₁ + W_j
D = C
C = B ≪ 9
B = A  
A = TT₁
H = G
G = F ≪ 19
F = E
E = P₀(TT₂)
```

**轮函数的非线性分析**：
每轮引入的非线性来源：
1. 布尔函数FF_j和GG_j的非线性
2. 模加法的进位传播
3. P₀置换的扩散效应

### 3.3 安全性数学证明

#### 3.3.1 抗碰撞性分析

**碰撞概率上界**：
对于随机选择的两个不同消息M₁, M₂，碰撞概率：
```
Pr[H(M₁) = H(M₂)] ≤ 2^{-256}
```

**生日攻击复杂度**：
```
T_collision ≈ √(π/2) × 2^{128} ≈ 1.25 × 2^{127}
```

#### 3.3.2 抗原像攻击分析

**原像攻击复杂度**：
对于给定的哈希值h，找到消息M使得H(M) = h的期望复杂度：
```
T_preimage ≈ 2^{256}
```

**第二原像攻击复杂度**：
对于给定消息M₁，找到M₂ ≠ M₁使得H(M₁) = H(M₂)的复杂度：
```
T_second_preimage ≈ 2^{256}
```

#### 3.3.3 差分攻击抵抗性

**差分路径概率**：
最佳差分路径的概率下界：
```
p_diff ≤ 2^{-s}
```

其中s是活跃S-box(非线性操作)的数量。

对于SM3的64轮结构，活跃操作数量满足：
```
s ≥ 64 × min_nonlinearity > 128
```

因此差分攻击复杂度超过2^128。

### 3.4 优化算法数学基础

#### 3.4.1 消息扩展优化

**递推关系矩阵表示**：
消息扩展可表示为线性变换：
```
[W_{16}]   [L₁₆×₁₆] [W₀ ]
[W_{17}] = [       ] [W₁ ]
[  ⋮  ]   [       ] [ ⋮ ]
[W_{67}]   [       ] [W₁₅]
```

其中L是稀疏的循环矩阵。

**批量计算优化**：
利用SIMD指令并行计算4个字：
```
W[j:j+3] = P₁(W[j-16:j-13] ⊕ W[j-9:j-6] ⊕ ROL(W[j-3:j], 15))
         ⊕ ROL(W[j-13:j-10], 7) ⊕ W[j-6:j-3]
```

#### 3.4.2 循环移位优化

**位操作等价性**：
```
ROL(x, n) = (x << n) | (x >> (32-n))
```

**SIMD向量旋转**：
```
__m128i ROL_128((__m128i x, int n) {
    return _mm_or_si128(_mm_slli_epi32(x, n), _mm_srli_epi32(x, 32-n));
}
```

#### 3.4.3 模加法优化

**并行模加法**：
32位模加法可分解为：
```
(a + b) mod 2³² = ((a mod 2³²) + (b mod 2³²)) mod 2³²
```

SIMD实现：
```
result = _mm_add_epi32(a, b);  // 自动模2³²
```

**进位预测优化**：
对于连续的模加法操作，可以预测进位模式以减少依赖。

## 4. 高级算法优化理论

### 1. 基础实现（basic）

**设计目标**: 严格按照国家标准实现，确保算法正确性
**特点**:
- 直接按照GB/T 32905-2016标准编写
- 代码结构清晰，易于理解和验证
- 无复杂优化，便于作为参考实现

**核心函数**:
```c

void sm3_basic_batch_hash(const uint8_t *data, size_t len, uint8_t *digest, int iterations);
```

### 2. SIMD优化实现（simd）

**设计目标**: 利用AVX2指令集实现向量化并行计算
**优化技术**:
- **8路并行**: 同时处理8个独立的哈希计算
- **向量化布尔函数**: FF/GG函数使用AVX2指令实现
- **并行消息扩展**: 批量处理消息扩展过程
- **向量化循环移位**: 使用位操作指令优化

**性能提升**:
- 理论并行度: 8倍
- 实际加速比: 3-5倍（考虑内存带宽限制）

**关键函数**:
```c
void sm3_simd_compress_8way(uint32_t state[8][8], const uint8_t blocks[8][64]);
void sm3_simd_batch_hash_8way(const uint8_t data[8][64], uint8_t digest[8][32]);
```

### 3. 高级优化实现（optimized）

**设计目标**: 通过多种优化技术最大化单线程性能
**优化技术**:

#### 循环展开（Loop Unrolling）
- 前16轮和后48轮分别展开
- 每次处理2轮减少循环开销
- 编译器能更好地进行指令调度

#### 预计算表格（Precomputed Tables）
```c
static const uint32_t T_TABLE[64] = {
 // 预计算的T值，避免运行时计算
};
```

#### 内存访问优化
- 数据结构对齐到缓存行边界
- 减少不必要的内存拷贝
- 优化数据局部性

#### 分支预测优化
- 减少条件分支
- 使用位操作替代条件判断
- 统一的代码路径

- **基础版本**: 适用于对性能要求不高但需要算法正确性保证的场景
- **SIMD版本**: 适用于批量处理和高吞吐量要求的场景
- **优化版本**: 适用于对单线程性能有较高要求的场景
