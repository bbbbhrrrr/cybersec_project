# SM2椭圆曲线数字签名算法优化实现技术文档

## 1. 项目概述

### 1.1 算法背景
SM2椭圆曲线数字签名算法是中国国家密码管理局发布的椭圆曲线公钥密码算法标准（GM/T 0003.2-2012）。SM2基于椭圆曲线离散对数难题的计算困难性，提供数字签名、密钥交换和公钥加密功能。

### 1.2 技术特性
- **安全强度**: 256位椭圆曲线提供128位等效安全强度
- **标准曲线**: 使用国密标准椭圆曲线参数
- **算法组件**: 包含数字签名、验证、密钥生成算法
- **哈希函数**: 配合SM3哈希算法使用
- **应用领域**: 数字证书、安全通信、身份认证

### 1.3 优化目标
- **性能提升**: 优化椭圆曲线运算性能
- **内存优化**: 减少内存占用和缓存未命中
- **算法优化**: 采用高效的椭圆曲线算法
- **工程实现**: 提供生产级的实现质量

## 2. 数学理论基础

### 2.1 椭圆曲线定义

SM2使用的椭圆曲线定义在有限域Fp上，曲线方程为：

```
E: y² ≡ x³ + ax + b (mod p)
```

其中：
- p是大于3的素数，定义有限域Fp
- a, b ∈ Fp，且满足判别式Δ = 4a³ + 27b² ≢ 0 (mod p)

**SM2推荐曲线参数**：
```
p = FFFFFFFE FFFFFFFF FFFFFFFF FFFFFFFF FFFFFFFF 00000000 FFFFFFFF FFFFFFFF
a = FFFFFFFE FFFFFFFF FFFFFFFF FFFFFFFF FFFFFFFF 00000000 FFFFFFFF FFFFFFFC  
b = 28E9FA9E 9D9F5E34 4D5A9E4B CF6509A7 F39789F5 15AB8F92 DDBCBD41 4D940E93
n = FFFFFFFE FFFFFFFF FFFFFFFF FFFFFFFF 7203DF6B 21C6052B 53BBF409 39D54123
Gx = 32C4AE2C 1F198119 5F990446 6A39C994 8FE30BBF F2660BE1 715A4589 334C74C7
Gy = BC3736A2 F4F6779C 59BDCEE3 6B692153 D0A9877C C62A4740 02DF32E5 2139F0A0
```

其中：
- p: 有限域的模数
- a, b: 椭圆曲线方程参数
- n: 基点G的阶
- G = (Gx, Gy): 椭圆曲线的基点

### 2.2 椭圆曲线群运算

#### 2.2.1 点加法运算

对于椭圆曲线上两个不同点P(x₁, y₁)和Q(x₂, y₂)，点加法P + Q = R(x₃, y₃)的计算公式：

**情况1：P ≠ Q（一般点加法）**
```
λ = (y₂ - y₁) · (x₂ - x₁)⁻¹ mod p
x₃ = λ² - x₁ - x₂ mod p
y₃ = λ(x₁ - x₃) - y₁ mod p
```

**情况2：P = Q（点倍乘）**
```
λ = (3x₁² + a) · (2y₁)⁻¹ mod p
x₃ = λ² - 2x₁ mod p  
y₃ = λ(x₁ - x₃) - y₁ mod p
```

**特殊情况**：
- 无穷远点O作为群的单位元：P + O = O + P = P
- 逆元：P + (-P) = O，其中-P = (x₁, -y₁ mod p)

#### 2.2.2 标量乘法运算

椭圆曲线标量乘法kP（k为正整数，P为椭圆曲线上的点）是椭圆曲线密码学的核心运算：

```
kP = P + P + ... + P (k次)
```

**二进制展开法**：
设k的二进制表示为k = Σᵢ₌₀ˡ⁻¹ kᵢ2ⁱ，则：
```
kP = Σᵢ₌₀ˡ⁻¹ kᵢ2ⁱP = Σᵢ₌₀ˡ⁻¹ kᵢ(2ⁱP)
```

**倍加法算法**：
```
算法：标量乘法kP
输入：k, P
输出：Q = kP
1. Q ← O
2. for i = l-1 down to 0 do
3.   Q ← 2Q
4.   if kᵢ = 1 then Q ← Q + P
5. return Q
```

### 2.3 模运算理论

#### 2.3.1 模逆运算

模逆运算a⁻¹ mod p（即找到x使得ax ≡ 1 (mod p)）使用扩展欧几里得算法：

```
算法：扩展欧几里得算法
输入：a, p (gcd(a,p) = 1)
输出：x = a⁻¹ mod p
1. 初始化：u₁ = 1, u₂ = 0, v₁ = 0, v₂ = 1, r₁ = p, r₂ = a
2. while r₂ ≠ 0 do
3.   q = ⌊r₁/r₂⌋
4.   (r₁, r₂) ← (r₂, r₁ - q·r₂)  
5.   (u₁, u₂) ← (u₂, u₁ - q·u₂)
6.   (v₁, v₂) ← (v₂, v₁ - q·v₂)
7. return u₁ mod p
```

#### 2.3.2 蒙哥马利模约简

对于大数模运算，蒙哥马利约简可以避免除法运算：

**蒙哥马利域**：将数a表示为aR mod n的形式，其中R = 2ᵏ > n

**蒙哥马利约简算法**：
```
算法：REDC(T)
输入：T < nR, n, n' (nn' ≡ -1 (mod R))
输出：TR⁻¹ mod n
1. m ← (T mod R) · n' mod R
2. t ← (T + mn) / R
3. if t ≥ n then return t - n else return t
```

## 3. SM2数字签名算法

### 3.1 密钥生成

**算法流程**：
```
1. 生成随机数d ∈ [1, n-1]（私钥）
2. 计算P = dG（公钥点）
3. 输出密钥对(d, P)
```

**数学表示**：
- 私钥：d ∈ Z*ₙ
- 公钥：P = (xₚ, yₚ) ∈ E(Fₚ)，满足P = dG

### 3.2 数字签名生成

**输入**：
- 消息M
- 私钥d
- 公钥P

**签名算法**：
```
算法：SM2_Sign(M, d)
输入：消息M, 私钥d
输出：签名(r, s)

1. 计算消息摘要：e = H(Z_A || M)
   其中Z_A是用户A的可辨别标识
2. repeat
3.   生成随机数k ∈ [1, n-1]
4.   计算椭圆曲线点(x₁, y₁) = kG
5.   计算r = (e + x₁) mod n
6.   if r = 0 or r + k = n then goto step 2
7.   计算s = (1 + d)⁻¹(k - rd) mod n  
8.   if s = 0 then goto step 2
9. until r ≠ 0 and s ≠ 0
10. return (r, s)
```

**数学关系**：
签名(r, s)满足：
```
s(1 + d) ≡ k - rd (mod n)
即：k ≡ s(1 + d) + rd (mod n)
```

### 3.3 数字签名验证

**验证算法**：
```
算法：SM2_Verify(M, (r,s), P)
输入：消息M, 签名(r,s), 公钥P
输出：Accept 或 Reject

1. 检查r, s ∈ [1, n-1]
2. 计算消息摘要：e = H(Z_A || M)
3. 计算t = (r + s) mod n
4. if t = 0 then return Reject
5. 计算椭圆曲线点(x₁, y₁) = sG + tP
6. 计算R = (e + x₁) mod n
7. if R = r then return Accept else return Reject
```

**正确性证明**：
```
验证等式：sG + tP = sG + (r+s)dG = (s + (r+s)d)G = (s(1+d) + rd)G

由签名生成算法：s(1+d) ≡ k - rd (mod n)
得：s(1+d) + rd ≡ k (mod n)

因此：sG + tP = kG
所以：x₁坐标相等，验证通过
```

## 4. 算法优化策略

### 4.1 椭圆曲线点运算优化

#### 4.1.1 雅可比坐标系

将仿射坐标(x, y)转换为雅可比坐标(X, Y, Z)，其中：
```
x = X/Z², y = Y/Z³
```

**优势**：避免除法运算，只需乘法和加法

**雅可比坐标点加法**：
设P₁ = (X₁, Y₁, Z₁), P₂ = (X₂, Y₂, Z₂)，计算P₃ = P₁ + P₂ = (X₃, Y₃, Z₃)：

```
U₁ = X₁Z₂², U₂ = X₂Z₁²
S₁ = Y₁Z₂³, S₂ = Y₂Z₁³  
H = U₂ - U₁, r = S₂ - S₁

X₃ = r² - H³ - 2U₁H²
Y₃ = r(U₁H² - X₃) - S₁H³
Z₃ = Z₁Z₂H
```

**复杂度分析**：
- 仿射坐标点加法：1I + 2M + 1S（I=逆运算，M=乘法，S=平方）
- 雅可比坐标点加法：12M + 4S
- 当I ≈ 80M时，雅可比坐标有显著优势

#### 4.1.2 NAF(Non-Adjacent Form)标量乘法

NAF是数的二进制表示的推广，允许使用{-1, 0, 1}：

**NAF性质**：
- 任何整数都有唯一的NAF表示
- NAF表示中相邻数位不全为非零
- NAF表示的非零位约为长度的1/3

**NAF生成算法**：
```
算法：Binary_to_NAF(k)
输入：正整数k
输出：k的NAF表示

1. i ← 0
2. while k > 0 do
3.   if k is odd then
4.     nᵢ ← 2 - (k mod 4)
5.     k ← k - nᵢ
6.   else nᵢ ← 0  
7.   k ← k/2, i ← i+1
8. return (n₀, n₁, ..., nᵢ₋₁)
```

**NAF标量乘法**：
```
算法：NAF_ScalarMult(k, P)
输入：标量k, 点P
输出：kP

1. 计算k的NAF表示
2. 预计算-P
3. Q ← O
4. for i = l-1 down to 0 do
5.   Q ← 2Q
6.   if nᵢ = 1 then Q ← Q + P
7.   if nᵢ = -1 then Q ← Q - P
8. return Q
```

#### 4.1.3 滑动窗口法

将标量k分解为固定窗口大小w的块，预计算奇数倍点：

**预计算表**：对于窗口大小w，预计算：
```
{P, 3P, 5P, ..., (2^w - 1)P}
```

**滑动窗口算法**：
```
算法：SlidingWindow_ScalarMult(k, P, w)
输入：标量k, 点P, 窗口大小w
输出：kP

1. 预计算奇数倍点表
2. Q ← O, i ← l-1
3. while i ≥ 0 do
4.   if kᵢ = 0 then
5.     Q ← 2Q, i ← i-1
6.   else
7.     找到最大的j使得kᵢ...kᵢ₋ⱼ₊₁为奇数且j ≤ w
8.     Q ← 2ʲQ + (kᵢ...kᵢ₋ⱼ₊₁)P
9.     i ← i-j
10. return Q
```

### 4.2 模运算优化

#### 4.2.1 Barrett约简

对于固定模数n，Barrett约简避免除法运算：

**预计算**：μ = ⌊2²ᵏ/n⌋，其中k满足2ᵏ⁻¹ ≤ n < 2ᵏ

**Barrett约简算法**：
```
算法：Barrett_Reduction(x, n, μ, k)
输入：x < n², 模数n, 预计算值μ
输出：x mod n

1. q₁ ← ⌊x/2^(k-1)⌋
2. q₂ ← ⌊q₁μ/2^(k+1)⌋  
3. r₁ ← x mod 2^(k+1)
4. r₂ ← (q₂n) mod 2^(k+1)
5. r ← r₁ - r₂
6. if r < 0 then r ← r + 2^(k+1)
7. while r ≥ n do r ← r - n
8. return r
```

#### 4.2.2 快速模逆算法

**二进制GCD算法**：
```
算法：Binary_GCD_Inverse(a, n)
输入：a, n (gcd(a,n) = 1)
输出：a⁻¹ mod n

1. u ← a, v ← n, A ← 1, C ← 0
2. while u ≠ 0 do
3.   while u is even do
4.     u ← u/2
5.     if A is even then A ← A/2 else A ← (A+n)/2
6.   while v is even do  
7.     v ← v/2
8.     if C is even then C ← C/2 else C ← (C+n)/2
9.   if u ≥ v then u ← u-v, A ← A-C
10.  else v ← v-u, C ← C-A
11. return C mod n
```

### 4.3 预计算表优化

#### 4.3.1 固定基点预计算

对于固定基点G，预计算表：
```
T[i][j] = (2^(jw))^i G, for i = 0,1,...,⌊256/w⌋-1, j = 0,1,...,2^w-1
```

其中w是窗口大小。

**预计算标量乘法**：
```
算法：FixedBase_ScalarMult(k, T, w)
输入：标量k, 预计算表T, 窗口大小w  
输出：kG

1. 将k分解为w位块：k = Σᵢkᵢ2^(iw)
2. Q ← O
3. for i = 0 to ⌊256/w⌋-1 do
4.   if kᵢ ≠ 0 then Q ← Q + T[i][kᵢ]
5. return Q
```

#### 4.3.2 同时多标量乘法(Straus算法)

计算k₁P₁ + k₂P₂时，同时处理两个标量：

```
算法：Straus_MultiScalarMult(k₁, P₁, k₂, P₂)
输入：标量k₁, k₂, 点P₁, P₂
输出：k₁P₁ + k₂P₂

1. 预计算组合点：T[i][j] = iP₁ + jP₂, for i,j ∈ {0,1,2,3}
2. Q ← O
3. for i = l-1 down to 0 do
4.   Q ← 4Q
5.   u ← 2k₁[i+1] + k₁[i], v ← 2k₂[i+1] + k₂[i]
6.   Q ← Q + T[u][v]
7. return Q
```

def optimized_scalar_mult(k: int, point: ECPoint) -> ECPoint:
    """优化的标量乘法实现"""

    return result

## 7. 安全性分析

### 7.1 数学安全性

**基础安全假设**：
- **椭圆曲线离散对数问题(ECDLP)**：给定P和Q = kP，计算k在计算上是困难的
- **随机预言机模型**：哈希函数H被建模为随机预言机

**安全性证明思路**：
```
定理：在随机预言机模型下，如果椭圆曲线离散对数问题是困难的，
则SM2数字签名方案满足存在性不可伪造性。

证明：通过规约证明，假设存在能够伪造签名的算法A，
可以构造算法B解决椭圆曲线离散对数问题。
```

### 7.2 实现安全性

**侧信道攻击防护**：
- **常时间实现**：确保运算时间不依赖于秘密数据
- **随机化技术**：对标量进行随机化处理
- **点验证**：验证椭圆曲线点的有效性

**常时间标量乘法**：
```python
def constant_time_scalar_mult(k: int, point: ECPoint) -> ECPoint:
    """常时间标量乘法实现"""
    # 蒙哥马利阶梯算法
    x1, z1 = point.x, 1
    x2, z2 = 1, 0
    
    for i in range(255, -1, -1):
        bit = (k >> i) & 1
        # 条件交换（常时间）
        x1, x2 = cswap(x1, x2, bit)
        z1, z2 = cswap(z1, z2, bit)
        
        # 蒙哥马利阶梯步骤
        x2, z2 = mont_ladder_step(x1, z1, x2, z2, point.x)
        x1, z1 = mont_double(x1, z1)
        
        # 条件交换（常时间）
        x1, x2 = cswap(x1, x2, bit)
        z1, z2 = cswap(z1, z2, bit)
    
    return convert_from_montgomery(x1, z1)
```

class SM2SecureChannel:
    """基于SM2的安全通信通道"""
    
    def __init__(self, private_key: int, peer_public_key: ECPoint):
        self.private_key = private_key

        """建立共享密钥"""
